# 休止符

[English](README.md)

在对话末尾保存私人结语，记录工作进度或理解笔记，而无需进一步对话。

支持 DeepSeek Harness 0.2.2-rc.5。

一轮结束后，在输入框写好草稿，按住 Mod（macOS 上是 ⌘，Windows 和 Linux 上是 Ctrl）。
草稿符合保存条件时，发送按钮的位置会显示休止符 `𝄽`。
点击它保存结语，松开 Mod 后恢复发送箭头。每个对话的最新结语保存在当前浏览器，显示在对应回合末尾。
结语气泡下方依次是**复制**、**回退**、**发送**。复制成功时，原图标会短暂变成勾。
输入框可用且为空时，回退把结语移回输入框供编辑，发送则把结语作为普通消息发出。

结语只保存草稿文字。从对话中选取的引用片段会保存为 Markdown 引用文本。
带附件、`@` 引用标签或以 `/` 开头的草稿继续使用普通输入框。
生成期间从结语点「发送」会排队。键盘沿用原生发送操作，保存结语请点击休止符。

在 **插件** > **添加插件** 中选择本目录即可安装。
开发检查见[项目文档](docs/README.md)。
