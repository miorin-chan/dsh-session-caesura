# 休止符

[English](README.md)

在对话末尾保存私人结语，记录工作进度或思考笔记而不继续触发新一轮对话。

- 回合结束后在输入框输入草稿，按住 `Mod`（macOS 为 `⌘`，
  Windows / Linux 为 `Ctrl`）点击 `𝄽` 或按 `Mod+Enter` 保存首条结语。
- 已有结语后，`𝄽` 会留在发送位，点击或按 `Enter` 即可追加段落（结语及 `@` 引用、引文和附件均保存在当前浏览器）。
- 结语下方显示最近保存时间以及 **复制**、**回退**（将全文移回空输入框继续编辑）和 **发送**（作为普通消息发出，
  支持以 `/` 开头的文本）。

需要 DeepSeek Harness `0.2.2-rc.5`。
可在 **会话模块化改良计划** 中直接开启 **休止符**，或在源码目录运行 `pnpm install` 后从 **插件 → 添加插件** 选择本目录。
