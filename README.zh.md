# 休止符

[English](README.md)

在对话末尾保存私人结语，记录工作进度或理解笔记，而无需进一步对话。

支持 DeepSeek Harness 0.2.2-rc.5。

一轮结束后，在输入框写好草稿，按住 Mod（macOS 上是 ⌘，Windows 和 Linux 上是 Ctrl）。
点击休止符 `𝄽` 或按 Mod+Enter 保存第一条结语。
会话有结语后，发送位置会持续显示休止符。点击它或按 Enter，把草稿追加到同一条结语。
追加的文字与上一段之间空一行，并更新保存时间。结语显示在最近一次保存的回合末尾。
浏览器支持 CSS `reading-flow` 时，结语位于回答操作栏下方。

结语保留文字、`@` 引用标签、选中的对话引用和文件附件，也支持只有附件的草稿。
图片可预览，音视频可用浏览器播放器播放，文件可下载。
结语和附件保存在当前浏览器。

气泡下方按本地时区显示最近保存时间，旁边是**复制**、**回退**、**发送**。
复制会取出文字，成功后短暂显示勾。输入框可用且为空时，回退把完整结语移回输入框供编辑。
点结语卡上的发送，卡片立即淡出，结语作为普通消息发出，包括以 `/` 开头的文字。
发送失败时，卡片恢复并显示提示。生成期间发送会排队。
Shift+Enter 用来换行。高亮的候选项和正在组字的输入法优先处理按键。
停止和继续生成仍可在对应状态下操作。

从源码安装时，先在检出目录运行 `npm ci` 构建插件，再在 **插件** > **添加插件** 中选择该目录。
开发检查见[项目文档](docs/README.md)。
