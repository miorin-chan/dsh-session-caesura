# 结语笔记

[English](README.md)

在 DeepSeek Harness 0.2.2-rc.5 的空闲对话中，可以留下一条只有自己看的结语。

一轮结束后，在输入框写好草稿，点击发送按钮旁的休止符 `𝄽`。每个对话的最新结语保存在当前浏览器，显示在对应回合末尾。
结语正文下方可以**复制**，也可以在输入框可用且为空时**发送**一份副本。

结语只保存草稿文字。从对话中选取的引用片段会保存为 Markdown 引用文本。带附件、`@` 引用标签或以 `/` 开头的草稿继续使用普通输入框。
生成期间从结语点「发送」会排队。Enter 和原生发送按钮沿用正常发送行为。

在 **插件** > **添加插件** 中选择本目录即可安装。开发检查见[项目文档](docs/README.md)。
