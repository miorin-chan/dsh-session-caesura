## 结语笔记的位置

在支持 `reading-flow` 的浏览器里，保存结语后检查对应回答的操作栏位于笔记上方。
比对原生用户消息的气泡和操作栏。结语的最近保存时间位于操作图标左侧，按浏览器本地时区显示，当天只显示时分。
连续保存两次，检查同一个结语气泡按保存顺序显示两段文字，中间恰好空一行，并显示第二次保存的时间。
刷新页面后检查时间和正文保留。旧版保存的结语仍能打开，只显示正文和操作图标，追加后显示新的保存时间。
发送下一条消息，检查结语仍跟在原回答之后。再次保存时，合并后的结语移到最新回合末尾。
点击回退应删除结语并把合并后的全文恢复到输入框。

2026-11-23 在 DSH 0.2.2-rc.5 的隔离 Chrome 会话中验证保存、旧笔记追加、刷新和回退。
比对了桌面浅色与 360 CSS px 深色视口中的原生气泡和时间，保存期间模型请求数不变。

只有结语时，Tab 从回答操作栏进入笔记操作区。
同一回合有其他尾部卡片时，Chromium 会把卡片和结语放进同一焦点组，Tab 可能先经过结语。

## 发送位置的休止符

`conversation.input.right` 在按住 Mod 且草稿合格时渲染一个绝对定位的按钮。
按钮沿用休止符原来的细描边和图标配色，使用输入框底色盖住发送箭头。
覆盖的尺寸和偏移取自 DSH 0.2.2-rc.5 的 `InputBar.module.css`，升级运行时后需重新比对。
`conversation.hero.frame` 在聚焦的原生编辑器中捕获 Mod+Enter，并调用按钮的保存动作。
录音展开时宿主隐藏右侧工具栏，按键交给原生编辑器。
麦克风收起后按当前 Mod 和草稿状态恢复休止符。

在隔离 profile 的 Chrome 中检查 1280、360、320 CSS px 的视口宽度。
休止符和原生发送的 34×34 px 边界重合，按键切换不移动工具栏，录音展开和取消均正确。
验证使用官方语音界面、Chrome 模拟麦克风，以及本地语音和模型夹具。
存储失败时保留原稿并显示提示，编辑草稿后提示消失。
点击休止符将原稿保存为本地结语，模型夹具的请求次数不增加。
普通点击和 Enter 均完成原生发送。
原生按钮预先获得焦点时，按住 Mod 显示休止符，松键后仍可按 Enter 发送。
