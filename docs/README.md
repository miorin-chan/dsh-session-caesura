## 结语笔记的原生样式

气泡、Tooltip、剪贴板写入以及复制和发送图标使用 Web shell 提供的 `@deepseek-ai/dsh-client-ui-primitives`。
回退按钮使用插件原来的撤销箭头，由原生操作栏样式控制尺寸和颜色。
聊天布局、操作栏样式与日期格式实现放在 `src/client/appearance.tsx` 和 `src/lib/clock.ts`，
尺寸与日期规则参考 `@deepseek-ai/dsh-client-ui-chat` 0.2.2-rc.5。
结语正文直接传入气泡，保留引用和追加段落之间的空行。

在支持 `reading-flow` 的浏览器里，保存结语后检查对应回答的操作栏位于笔记上方。
比对原生用户消息的气泡和操作栏。结语的最近保存时间位于操作图标左侧，按浏览器本地时区显示，当天只显示时分。
先保存 Markdown 引用，再追加普通文字，检查同一个气泡按保存顺序显示两段文字，中间恰好空一行，并显示第二次保存的时间。
刷新页面后检查时间和正文保留。旧版保存的结语仍能打开，只显示正文和操作图标，追加后显示新的保存时间。
发送下一条消息，检查结语仍跟在原回答之后。再次保存时，合并后的结语移到最新回合末尾。
点击回退应删除结语并把合并后的全文恢复到输入框。

2026-11-23 在 DSH 0.2.2-rc.5 的隔离 Chrome 会话中验证保存、旧笔记追加、引用空行、刷新和回退。
比对了桌面浅色与 360 CSS px 深色视口中的原生气泡和时间，并检查了中英文日期格式。
保存期间模型请求数不变。同日接入官方组件和样式后，在隔离 Chrome 中重新比对了复制图标、气泡、按钮和时间的计算样式。
实测 Tooltip、复制成功与失败提示、禁用按钮的可访问说明、回退和发送。

只有结语时，Tab 从回答操作栏进入笔记操作区。
同一回合有其他尾部卡片时，Chromium 会把卡片和结语放进同一焦点组，Tab 可能先经过结语。

## 发送位置的休止符

`conversation.input.right` 将按钮定位在原生发送位置。
空闲会话可按住 Mod 保存第一条结语。已有结语时，按钮随会话保留，空草稿时禁用。
按钮沿用原来的细描边和图标配色，原生发送按钮退出焦点顺序。
尺寸和偏移取自 DSH 0.2.2-rc.5 的 `InputBar.module.css`，升级运行时后需重新比对。
`conversation.hero.frame` 捕获聚焦编辑器的发送键，并调用同一个保存动作。
选项菜单和输入法继续优先接收按键。原生停止和继续生成保留主按钮位置。
录音展开时，有结语的会话仍可追加；首次保存随普通工具栏收起。

在隔离 profile 的 Chrome 中检查 1280、360、320 CSS px 的视口宽度。
休止符和原生发送的 34×34 px 边界重合，按键切换不移动工具栏，录音展开和取消均正确。
验证使用官方语音界面、Chrome 模拟麦克风，以及本地语音和模型夹具。
存储失败时保留原稿并显示提示，编辑草稿后提示消失。
点击休止符将原稿保存为本地结语，模型夹具的请求次数不增加。
第一次保存前，普通点击和 Enter 执行原生发送。若原生按钮已获得焦点，松开 Mod 后仍可按 Enter 发送。
Mod 按 DSH 的桌面平台标记识别，Web 页使用浏览器平台。
主修饰键自己的按下事件可以缺少修饰位。

## 原生草稿与附件

结语文本和语义范围保存在原来的浏览器存储键。
旧版纯文本结语仍可读取。媒体保存为 IndexedDB 中的原始 `File`。
存储成功后才清空输入框，并用草稿版本和附件顺序判断保存期间是否发生编辑。
图片通过原生图片工厂显示，音视频使用浏览器播放器。
回退通过 DSH 0.2.2-rc.5 的会话输入对象恢复引用、引文和附件。
结语卡的发送使用原生引用序列化与附件提交。行首斜杠按消息文本发送。
点击发送时检查卡片立即开始淡出，系统启用「减少动态效果」时直接隐藏。
发送成功后刷新页面，确认卡片不再出现。
模拟发送失败，确认原笔记和附件恢复，并显示错误。

在隔离 profile 验证点击、Enter、刷新和附件单独保存。
核对本地笔记、模型请求计数、原生发送的计算可见性和回退后的草稿。
